# ULTRA para Android

## Descargar

[Descargar ULTRA.apk](https://ultrafuture.co/app)

La descarga es pública y no requiere invitación ni cuenta de Firebase. Abre la
APK descargada y confirma su instalación en Android. Puede aparecer una solicitud
para permitir instalaciones desde tu navegador. El inicio de sesión dentro de
ULTRA sigue siendo el habitual.

La APK conserva la identidad de la beta anterior para actualizar sin desinstalar.
Esta versión utiliza la plataforma y los datos reales de ULTRA.

## Actualizaciones

El enlace anterior siempre apunta a la beta más reciente publicada aquí. La
sincronización comprueba Firebase cada 15 minutos; GitHub puede retrasar las tareas
programadas. Las nuevas APK requieren que confirmes su instalación. Los cambios
de la web llegan al cargarla, sin instalar otra APK.

Este repositorio solo contiene la automatización y los archivos públicos de
descarga. El código de la aplicación Android se conserva en un repositorio privado.
La sincronización usa una identidad temporal de solo lectura de App Distribution,
sin claves privadas de Google guardadas en el repositorio.
